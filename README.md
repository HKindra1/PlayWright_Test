# PlayWright

This repository contains JavaScript practice files and Playwright-related learning exercises.

## Folder structure

- `01_Chapter_JavaScript/` - JavaScript basics and exercises
- `02_Chapter_LetConcept/` - Let, conditions, loops, patterns, and practice programs
- `09_Array/` - Array-related examples
- `Test_20Aug2026/` - Practice/test files from 20 Aug 2026

## How to run a JavaScript file

Open a terminal in the project folder and run:

```bash
node filename.js
```

Example:

```bash
node 01_Chapter_JavaScript/1_HelloWorld.js
```
